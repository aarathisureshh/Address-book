TITLE: Address Book Management System
NAME: ARATHI V

DESCRIPTION
A console-based C application for managing contact details. It supports adding, viewing, searching, editing, deleting, sorting, and saving contacts. The project demonstrates structured programming, input validation, and file handling.

FEATURES
- Add and view contacts
- Search contacts by name, phone number, or email
- Edit and delete contacts
- Sort contacts by name, phone number, or email
- Save contact data to a file
